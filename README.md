## 一、IEPL / IPLC 是什么，为什么要找专线服务商

IEPL 全称 **International Ethernet Private Line**（国际以太网专线），IPLC 是 **International Private Leased Circuit**（国际私有租用线路）。两者都通过运营商之间的点对点专线承载跨境流量，区别主要在底层技术：IEPL 用以太网二层，IPLC 用传统租用线路。不过对终端用户来说，更值得关注的不是技术名词，而是这几条事实：

- 这类「专线 VPS」交付时已经是一台配置过的云服务器，每台分配 1 个独立入口 IP 和 1 个独立出口 IP，你不需要再申请裸线路；
- 运行模式是「出口只出不入」，适合在 VPS 内访问海外后台、上传素材、调用授权 API、做客户端测试，**不适合用来做公开网站、买家支付回调或对外游戏服务端**；
- 走的是运营商之间的固定通道，相对公网有更稳定的延迟和抖动，但不能因此把它包装成「金融级」「零风险」，标准产品默认无 SLA。

也就是说，IEPL / IPLC 不是「更快一点的 VPN」，而是把跨境访问从「按需拨号」改成「走固定通道、独立 IP、独立配额」的一种交付方式。

| 维度 | 为什么重要 | 容易踩坑的地方 |
| --- | --- | --- |
| 出口方向 | 销售目标或 API 在哪里就该选哪条 | 香港出口不等于美国 IP，买家地区和实际节点不在一个国家 |
| 国内入口 | 决定了你能从哪些省份连入 | 直连款一般绑定一个省份，IX 款要求云厂 BGP 前置 |

## 五、共享和独享的选择边界：什么时候该加钱

两类套餐都是「单端双独立 IP」，共享与否和 IP 是否独立无关，差别在计费方式：

| 维度 | 共享（流量计费） | 独享（带宽计费） |
| --- | --- | --- |
| 计费单位 | 月流量 GB / TB | 固定 Mbps |
| 峰值带宽 | 给一个上限，不保证持续跑满 | 等于实际可用带宽 |
| 月流量上限 | 有，超量暂停 | 无 |
| 适合场景 | 间歇办公、后台访问、上传少量素材 | 持续传输、直播推流、定时同步 |
| 主要限制 | 不可作为长期大宗流量的默认方案 | 价格随档位跳档，5G 档每月可在数千至数万元 |

简而言之：能预估月流量、且主要时段不集中、跑得满速率就用共享；每天都要发起长传输、且有时间窗口要求，再考虑独享。预算紧的中小卖家从 1TB / 2TB 共享起步更划算。

## 六、付款、测速与验收：几点容易踩雷的细节

谈 IEPL 服务商时，套餐价格只是其中一环。下面这些细节 Mkcloud 在条款里写清楚了，也适用于行业一般情况，建议逐条核对：

- **实名与省份白名单**：所有专线产品都需要中国身份实名，直连款绑定一个连入省份，开通后仅允许指定省份 IP 连入，可以后期修改，但开通后不支持更换到其他地域产品。
- **出口单向**：VPS 出口只用于向外访问，不支持外部连入，因此不要把它假设成双向专网。
- **退款条件**：仅支持符合条款的质量问题退款，需要在工单中提交准确延迟数据、速度数据等证据；不是无条件试用。
- **超量停机**：计量型套餐按上行 + 下行双向统计，超量后暂停，可以自助购买流量重置或工单补差价升级。
- **升降级**：都通过工单处理；降级至价格更低的套餐时差价不退。

测速建议：把链路拆成两段分别测——本地到入口（验证省份白名单 + 网络接入）+ VPS 到目标服务（验证出口线路）。保存测试时间、目标、方式和原始截图，作为后续工单凭据。

## 七、常见问题 FAQ

**Q1：IEPL 和 IPLC 到底选哪个？**
两者名称只是侧重点不同，不能机械地把 IPLC 当成「更高级」。在 Mkcloud 的产品里，广港走的是 IEPL 方向，沪港、沪日、沪美则归在 IPLC。选哪个应该按出口方向和接入条件匹配，不能用名称排序。

**Q2：端内 3ms 就是我访问海外网站的速度吗？**
不是。端内延迟只是 VPS 入口到出口这一段，本地到入口和出口到目标网站都不算在 3ms 里。综合测速必须拉完整链路。

**Q3：独享不限流量是不是无限速？**
不限流量是不设置月流量额度，但速率仍受带宽档位、CPU、磁盘和目标服务限制。如果瓶颈在对方平台或磁盘，提高专线档位不会等比例改善实际速度。

**Q4：上海 CN2 是不是美区最快？**
不是。上海 CN2 是国内出口优化产品，面向需要国内出站组合的场景，不提供美国出口。要美区业务请直接看沪美 IPLC / 沪美 IX。

**Q5：广港 IEPL 能不能用来挂美区 IP？**
广港出口是香港 BGP，不是美国原生 IP。买家地区为美区时，应优先评估沪美或对应美国方向产品，不要因广港段延迟低就误判出口归属。
